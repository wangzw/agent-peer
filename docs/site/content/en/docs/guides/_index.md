These guides walk through the tasks agent-peer is built for. Each one starts from a working install.

- [Pair two hosts]({{< relref "pair-hosts.md" >}}): set up the link between two Brokers.
- [Collaborate in a topic]({{< relref "collaborate-in-topic.md" >}}): exchange messages between sessions that work on the same project.
- [Discover and connect a public Broker]({{< relref "public-brokers.md" >}}): find a Broker through the network and pair with it.
- [Run the Broker as a service]({{< relref "run-as-service.md" >}}): keep the Broker running at login or at boot.
- [Run a system Broker]({{< relref "system-broker.md" >}}): serve several accounts on one host.
- [Manage a Broker by file permission]({{< relref "management-permissions.md" >}}): explain who can change what.
