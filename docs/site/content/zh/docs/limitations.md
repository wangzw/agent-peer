agent-peer 能做本站其他页面介绍的事；做不到的部分，本页逐条说明。清单长是有意为之：了解边界，才知道怎样安全地使用。

## 消息

- 消息只传纯文本，不传文件、会话历史与上下文。
- 消息不缓存、不持久化、不重投。主机不可达时，发送返回错误，要不要重发由发送方 Agent 决定。
- 发送成功只表示消息已经写进目标会话的 inbox socket，不表示目标模型已读或已处理，之后也不会有通知说明结果。
- 投递请求已经发出、却没有收到明确答复时，调用返回的是“送达情况未知”，既不是成功，也不是失败。
- 限速、去重和待处理消息的排队上限都是接收端 Claude Code 的规则。它们怎么起作用、agent-peer 为什么不自己做，见[安全模型]({{< relref "security.md" >}})。

## 连接

- Broker 之间直接连接，消息不经第三个 Broker 转发，也没有集中式注册中心。两台主机互相都连不上时，比如都在 NAT 后面，就无法通信。
- 默认监听端口是 17443。配置的监听地址绑定不了时，Broker 启动失败，不会另选地址或端口。
- 不与外部 A2A agent 互通。

## 平台与账户

- agent-peer 运行在 macOS 与 Linux 上，支持 amd64 与 arm64。不支持原生 Windows。
- 每个账户至多运行一个 Broker。
- macOS 二进制没有签名，也没有经过公证。用浏览器下载的归档，运行前要清除隔离属性。
- Linux 发布版二进制以 `CGO_ENABLED=0` 构建，只从 `/etc/passwd` 与 `/etc/group` 读取账户。系统级 Broker 无法为 LDAP、SSSD 这类目录服务提供的账户派生辅助进程，也不能用它们的组关系判定配置文件权限。无法确定这类账户的主目录时，使用 `HOME`。
- 系统级服务的安装与运行只在 Linux 上做过端到端验证。macOS 上的服务安装需要人工验证。

## 会话与运行

- inbox socket 的消息格式与会话注册表没有公开的兼容承诺。Claude Code 升级可能破坏登记或投递。
- 有些会话无法成为 Agent：不绑定 inbox socket 的会话，Claude Code 没有为其保留会话注册表记录的会话（包括从另一个会话的命令行启动的交互式会话），以及名字不可用的会话。
- 由 MCP 服务进程自动启动的 Broker，标准输出与标准错误都接到 `/dev/null`，因此没有运行日志。要看日志，在终端运行 `agent-peer broker`，或把 Broker 安装成服务。
- MCP 服务进程崩溃后，交互式会话不会自动重启它。握手超过 30 秒或进程启动失败时，该服务被标为失败，用户要在 `/mcp` 里手动重连。
- 调用方账户读不了配置文件时，`agent-peer status` 的对端部分显示 `Peers: none`，分不出是真的没有对端，还是没有权限查看。
- 操作系统账户是隔离边界。同一账户下运行的任何进程，都能把该账户的任意会话登记为 Agent 并冒用它的身份。

## 尚未在真实会话中验证

下列行为尚未在经 agent-peer 运行的真实 Claude Code 会话中确认。在确认之前不要依赖它们。

- 会话自动登记；改名、清空对话、停用后重新启用 MCP 服务，都会按本站描述的方式体现出来。
- Agent 地址里的消歧标识与 Claude Code 会话列表中显示的标识相同，并且在改名和清空对话之后保持不变。
- 列表中的状态原样取自会话注册表。
- 投递的消息能让空闲会话在无人输入的情况下开始处理。
- 忙碌的会话何时读到投递的消息。
- 会话以跳过权限确认的模式运行、又没有入站策略时，是否把收到的消息留待批准；无界面会话在这种情况下能否收到消息。
- 接收方会话看到发送方的 Agent 地址，按这个地址回复能送达发送方；名字过长或含特殊字符时，通过消歧标识和截短处理。
- 目标会话的入站控制决定消息是被接收、留待批准还是拒收。
- 子代理以主会话的身份调用工具；无界面或运行在 IDE 中的会话与交互式会话一样登记。
- Claude Code 的权限设置能分别授权读取配置、修改配置和生成配对密钥。
- 说明工具用法之后，模型会用 `send_message` 回复 Agent 地址，而不是改用别的工具。
- 会话因为 inbox 的绑定晚于 MCP 服务进程启动而没有登记的频率。
- 子会话是否沿用父会话的 inbox socket 环境变量，沿用会让子会话登记到父会话的 Agent 名下。
- macOS 与 Linux 上会话注册表的文件变化通知，包括改名之后列表里的名字会不会随之更新。
- 消息经同一个 Broker 进程写入时，接收端 Claude Code 怎样限速和去重。
- macOS 上 LaunchAgent 在登录后启动用户级 Broker 并恢复链路。
